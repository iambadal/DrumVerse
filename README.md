# 🥁 DrumVerse

DrumVerse is a modern virtual drum kit built with React and Vite. It provides an interactive drum-playing experience with a clean UI, realistic drum layout, keyboard support, and smooth animations.

## ✨ Features

- 🎵 Interactive drum kit
- ⌨️ Keyboard controls
- 🖱️ Mouse click support
- 🎨 Modern responsive UI
- 🔊 High-quality drum sounds
- ⚡ Smooth animations
- 📱 Responsive design

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/iambadal/DrumVerse.git
```

Go to the project folder:

```bash
cd DrumVerse
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
